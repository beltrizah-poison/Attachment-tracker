# Attachment Tracker

A simple web app to track job applications. Built with HTML, CSS, and JavaScript.

## Features
- Add, edit, and delete applications
- Track company, position, location, date, status, and notes
- LocalStorage persistence (data stays after refresh)
- Summary counters (total, interviews, accepted)
- Clear All button with confirmation
